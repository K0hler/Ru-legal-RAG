# М1-04А: карта задачи (состояние на 25.10.2026)

Одна страница, чтобы не путаться: что мы строим, чем меряем, какие версии были и что показала каждая мера.
Подробности — в отчётах по ссылкам. План на ближайшее время — [цикл 9](../../../plans/2026-10-25-m1-04a-cycle-9.md).

## 1. Что строим

**Второй слой:** из размеченного OCR текста скана построить дерево владельцев — для каждой области страницы сказать,
чьё это: акта (`A`), утверждённого документа (`S`, `S2`…), приложения (`…/AN1`), статьи, части, пункта, подпункта.

- **Первый слой** — скан → строки (OCR dots.mocr, шум, склейки). Это задача М1-04 и М1-04B, здесь он дан.
- **Второй слой** — строки → дерево. Это и есть М1-04А. Код: один прототип `docs/assets/ocr_logical_structure.py`.
- Прототип развивается **версиями** (v1 … v7). Каждая версия — заморозка копии кода после **цикла** доработок.

## 2. Чем меряем: два стенда

| Стенд | Что внутри | Эталон | Чем силён | Слабое место |
|---|---|---|---|---|
| **Пул сканов** (`documents/pool/batch-NN`) | оригиналы публикаций PDF → OCR; партии по 8–11 актов разных видов | слепая разметка Codex по [соглашению v2](M1_04A_ANNOTATION_CONVENTION_v2.md) | настоящие сканы, приказы, СанПиН-подобные | эталон делает модель, данных мало |
| **Корпус официальных деревьев** (`json-corpus/20261025-v1`) | 100 актов IPS: HTML + дерево JSON; чистый текст, без OCR | автоматическая проекция дерева (проекция 4) | сотни тысяч узлов бесплатно, сложная структура | нет OCR, нет приказов и СанПиН, формы не размечены |

**Мера и разработка — главное правило протокола** ([протокол](M1_04A_EVALUATION_PROTOCOL_2026-10-20.md)):
- **Мера** — замороженная версия, новые данные, эталон заморожен до прогона, прогон один. Только это — прогресс.
- **Разработка** — всё, на чём правила уже писались или что уже измерено. После меры партия (или holdout) переходит
  в разработку и годится только для регрессии.
- **Регрессия** — прогон рабочего кода по всем данным разработки: ни один документ не должен стать хуже базы.
  Пул: `run_m1_04a_dev_regression.py` (сейчас 78 документов: 8 старых + партии 1–7). Корпус: `m1_04a_json_baseline.py`.

Основная метрика — **доля верных владельцев «без разделов»**. Пороги готовности (§7): ≥ 99% с первого раза,
`cross_scope_v2` = 0 (нет переносов текста в чужой документ), три партии подряд без нового класса ошибок.

## 5. Решения владельца по соглашению

| Дата | Решение |
|---|---|
| 21.10 | СП = СанПиН с тем же номером; утверждённый текст ≡ приложение к акту; разнообразный пул с эталоном Codex |
| 22.10 | приложения приложенного документа — `S/AN<n>`; «N.M» вкладывается под существующий «N.»; единственное `AN` = `AN1` |
| 23.10 | приложенные документы сравниваются по порядку; таблицы и их рубрики — текст объемлющей единицы |
| 25.10 | (§6.1) формы и договоры имеют свои пункты; абзац после последнего подпункта — родителю; черта — своему документу; документ с грифом — отдельный; форма без своей шапки внутри приложения — часть приложения; «Лист согласования» — форма класса «подписной блок» |

26.10: «1.» внутри раздела концепции — пункт, а не раздел (§6.1; стенд корпуса — проекция 5).
