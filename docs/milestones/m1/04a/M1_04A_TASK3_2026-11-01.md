# М1-04А: проверка структуры на четырёх отложенных документах

Дата: 01.11.2026. **Статус: проверка выполняется; результата приёмки пока нет.**

## Что проверяем

Task 3 проверяет, сможет ли закреплённая программа построить структуру документов,
которые не использовали для её доработки. Сначала независимые исполнители читают OCR
и смотрят каждую страницу сканов, затем результат программы сравнивается с их разметкой.
Проверяются все пункты, их родители и порядок, приложения, таблицы, сноски, продолжения
через страницу, сохранность исходного текста и координат. Одного общего процента недостаточно.

Владелец исключил сверку реквизитов из критериев М1-04А и Task 3. Неподтверждённые
реквизиты сохраняются отдельно и не мешают строить структуру. Проверки исходных файлов,
разрешений обработки и отдельные ограничения юридического допуска остаются.
Это уточнение внесено в планы, код и обе связанные карточки Trello.

Независимая разметка завершена и закреплена для всех четырёх документов:

Программа построения структуры на этих четырёх документах пока не запускалась.

Прежние замечания к границам исходных деревьев сохранены; они не исправлялись этой работой.

Локальные доказательства находятся в
`data/m1/m1-04a/experiments/20261101-task3-01/`:

- `evaluation/` и `parser-transfer-report.json` — будут записаны при сравнении.

## Границы результата

Два постановления и два санитарных документа проверяют только заявленные начальные
виды документов. Это не проверка всех законов, кодексов, приказов или любых сканов.
Просмотр страниц исполнителями не является юридическим допуском редакций.
Все PDF пока сохраняют `pdf_structure_unqualified`.

Ошибки этой проверки сохраняются. Изменение правил по ним сделает соответствующие
документы материалом доработки; для новой независимой проверки понадобятся другие документы.
