# Автоматический поворот страниц перед dots.mocr

Подключён [RapidOrientation 0.0.11](https://github.com/RapidAI/RapidOrientation) —
готовый модуль с четырёхсторонним классификатором PaddleClas, лицензия Apache-2.0.
Он работает локально на CPU через уже установленный ONNX Runtime. Текст по-прежнему
распознаёт прежний dots.mocr, с прежними весами, запросом и параметрами.

У PaddleOCR также есть отдельный [модуль ориентации документа](https://paddlepaddle.github.io/PaddleX/latest/en/module_usage/tutorials/ocr_modules/doc_img_orientation_classification.html).
RapidOrientation выбран из-за совместимости с нашим готовым Docker: не требуются
Paddle/PaddleX или обновление Transformers, от версии которого зависит dots.mocr.
Это выбор вспомогательного модуля, без повторного выбора движка OCR.

Входной скан сначала проверяется на поворот 0/90/180/270°. Поворот применяется
при уверенности модели не ниже 85%. Наша небольшая обвязка
читает оценки готовой модели: публичный API модуля возвращает только угол и время.
Оригинальный PNG сохраняется, координаты распознанных блоков возвращаются к нему;
предсказание, уверенность и координаты отправленного изображения остаются в JSON.

Готовый модуль берёт центральный фрагмент, который на разреженной странице может
оказаться пустым. Первый полный прогон ошибочно перевернул почти пустую страницу 4
ПП №1455. Уверенность составляла лишь 26,7%; основной текст сохранился, но
ухудшилась служебная надпись у штрихкода. Ошибочный прогон сохранён отдельно
в `20261103-ocr-fix-orientation-01`, исправленная проверка — в `...-02`.

Включение: `page_orientation: true` в конфигурации OCR. Флаг уже добавлен в
локальную рабочую конфигурацию и в пример `docs/assets/m1_04_ocr_recovery_config.example.json`.
Для воспроизведения на установленном OCR-Lab применить
`docs/assets/ocr_lab_page_orientation.patch` после предыдущего page-recovery patch,
затем выполнить `docker compose --project-directory H:/AI_AGENT/OCR-Lab build dotsmocr`.
Версия пакета, SHA-256 wheel/весов и фактический Docker image ID фиксируются.

Окончательная проверка (`20261103-ocr-fix-orientation-02/verification.json`):

- ФСТ №155: все 9 страниц распознаны; на странице 4 восстановлен заголовок
  «до 0,01 включительно», тариф для населения правильно связан с 157,73.
- Минсельхоз №235: все 47 страниц распознаны; на странице 36 исправлена привязка
  четырёх видов к Чёрному морю и возвращены два вида для пастбищной аквакультуры.
- Три прежних контрольных акта, 10 страниц: текст, типы и порядок блоков сохранены.
  Сомнительный поворот страницы ПП №1455 не применён. Все 66 исходных PNG неизменны.
- Пять новых результатов точно воспроизводятся из сохранённого OCR; прежние
  229+11 прогонов и 628 файлов исходной проверки не изменились.
- 1340 тестов, Ruff, M0 78/78; четыре проверки внешней обвязки без GPU.
  Отдельно сохранены 20 проверок углов и 12 проверок уверенности.

Это проверка двух проблемных таблиц и трёх контрольных актов, а не гарантия для
любого скана. Смешанное направление текста остаётся ограничением. В латинском
названии трепанга остаётся ошибка OCR; поворот её не исправил. Пустые формы и
точная геометрия пустых ячеек в эту доработку не входили.
