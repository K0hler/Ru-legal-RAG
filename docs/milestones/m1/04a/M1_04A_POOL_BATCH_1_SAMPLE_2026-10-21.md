# М1-04А, партия 1: выборка «текст → владелец» для просмотра

Дата: 21.10.2026. Дополнение к отчёту [M1_04A_POOL_BATCH_1_2026-10-21.md](M1_04A_POOL_BATCH_1_2026-10-21.md).

**Зачем.** Эталон этой партии разметил агент (Codex), а не человек. Эта выборка
даёт владельцу возможность выборочно проверить разметку. Просмотр необязателен.

**Как выбрано.** 30 областей из 363 размеченных, случайно, `random.Random(20261021).sample`.
Порядок генеральной совокупности — порядок строк в файлах эталона, акты в порядке
`freeze.json`. Машинная копия с полным текстом:
`data/m1/m1-04a/experiments/20261021-batch-01-first-pass/sample-30.json`;
воспроизводится `docs/assets/run_m1_04a_first_pass.py sample`. Выборка сделана
из всех 363 областей, до перехода на [соглашение v1](M1_04A_ANNOTATION_CONVENTION_v1.md):
картинки (строка 13) по нему не оцениваются.

**Как читать.** «Текст» — то, что распознал OCR в этой области (до 200 знаков,
`¦` заменяет вертикальную черту). «Владелец» — запись эталона:

- `A` — сам акт (закон, указ, постановление, приказ, распоряжение);
- `S`, `S2` — первый и второй приложенный документ (утверждённые правила,
  перечень, проект соглашения);
- `ст1`, `ч2` — статья 1, часть 2; голые числа — пункты; буквы — подпункты;
- `(+)` — область продолжает абзац с предыдущей страницы или области.

Столбец «Прототип» — совпал ли с эталоном прототип при прогоне с первого раза
(дан для справки; проверять нужно эталон, а не прототип).

Если владелец указан неверно, достаточно сообщить номер строки и правильного
владельца.
