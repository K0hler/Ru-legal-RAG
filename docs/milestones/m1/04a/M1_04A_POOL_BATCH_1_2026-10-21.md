Отбор — случайный, только по метаданным ленты publication.pravo.gov.ru
(seed 20261021, даты 2015–2025, квоты: 2 закона, 1 указ, 2 постановления,

изменяющие акты — 323, не найдено поиском по номеру и дате — 296, больше
одной редакции — 7.

Перекосы, которые надо держать в голове:

- **7 из 8 актов короткие, 3–9 страниц.** Только приказ №901 длинный
  (46 страниц), и он почти весь — одна таблица.
- **Оба закона — одного дня (19.02.2018) и одного вида** (упразднение судов).
  По сути это один образец закона в двух экземплярах.
- **Поиск в actual.pravo.gov.ru не дал ни одного попадания.** Из 311 поисков
  по номеру и дате все найденные записи — из IPS (все 8 отобранных актов;
  у 7 отклонённых по числу редакций источник в `selection.json` не записан,
  0 из 311 — по проверке финального ревью). 296 карточек не нашлись ни там,
  ни там — в основном приказы ведомств. Значит, в партию попадают только акты,
  которые находит поиск IPS; это отбор по доступности, а не только по

## 3. Эталон и его ограничения

- План предполагал автоматический эталон из официального структурного дерева.
  Дерево удалось получить только для **1 акта из 8** (IPS не отдаёт структуру
  четырёх актов; у единственной редакции IPS `rdk = 0`; нет правил идентичности
  для указов и приказов). По решению владельца 21.10.2026 эталон разметил
  **агент (Codex)** по OCR-тексту областей.
- Официальный текст был доступен для 4 актов (pp-1455, pp-884, prikaz-173,
  ukaz-204). По записям разметчика сверка с ним сделана для трёх (pp-1455,
  pp-884, ukaz-204); для prikaz-173 официальный текст не открывался, так как
  номера и границы читались однозначно.
- **Один разметчик**, без второго мнения. Разметчик работал по распознанному
  тексту; изображения страниц смотрел точечно: по заметкам — физическая
  страница 4 PDF pp-1455 (пустая картинка `4.2` — завершающая горизонтальная
  черта) и страница 3 PDF pp-884 (отдельный блок названия Правил). Остальные
  страницы и акты по изображениям не сверялись. Ошибки OCR (например, дата
  «18» августа вместо 28 в приказе №901) в эталоне не исправлялись — эталон
  задаёт владельца, а не текст.
- **Что разметчик видел.** Вход разметчика
  (`experiments/20261021-batch-01-annotation-input/`) — по одной строке на
  фрагмент области: категория OCR, текст, а также номер логического абзаца `P`
  и склейка `join` слоя логического текста (этап 2). Выходов этапа 3 (владельцев
  прототипа и `/7`) разметчик не видел, поэтому **владельцы размечены вслепую
  относительно проверяемых систем**. Признак продолжения `+` — нет: склейки
  этапа 2 были перед глазами, поэтому метрика склейки (раздел 4) на этой
  партии **не измерена независимо**. Начиная с партии 2 вход строится без
  `P`/`join` и без картинок ([соглашение v1](M1_04A_ANNOTATION_CONVENTION_v1.md), раздел 6).
- Эталон и заметки заморожены до прогона
  (`experiments/20261021-batch-01-gold-freeze/freeze.json`).
- **Приказ №901 почти весь — одна большая таблица:** 51 из 73 областей
  принадлежат перечню `S` целиком. Высокий процент на нём мало говорит
  о разборе структуры — достаточно правильно открыть приложение.
- Для необязательного просмотра владельцем отобраны 30 случайных областей

- **Почему класса «реквизиты» не было в журнале санитарных правил.** Главная
  причина — картинки там не оценивались: 19 из 36 ошибок этого класса на всех

  нормы в прежних документах журнала, отдельно не проверялось.

## 6. Что не измерялось

- Точность OCR и текста областей; изображения страниц сверялись только
  точечно (раздел 3).
- Склейка продолжений — независимо (разметчик видел склейки этапа 2).
- Владельцы сносок и таблиц как отдельная метрика; ячейки таблиц.
- Исключение колонтитулов (верно / ложно) — эталон перечисляет только
  содержательные области.
- Помеченные против молчаливых ошибок считались только по признаку «есть
  владелец / нет владельца», без меток неуверенности.
- Dedoc и LLM-гибрид на этой партии не запускались.
- Кодексы, изменённые законы, изменяющие акты с цитатами поправок, акты
  с разделами и длинные нормативные тексты в партию не входили.
- Повтор прогона на побайтное совпадение не делался (по протоколу —
  один прогон).
