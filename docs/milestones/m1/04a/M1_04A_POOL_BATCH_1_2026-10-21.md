## 2. Состав партии и перекосы отбора

Отбор — случайный, только по метаданным ленты publication.pravo.gov.ru
(seed 20261021, даты 2015–2025, квоты: 2 закона, 1 указ, 2 постановления,
1 распоряжение, 2 приказа; 3–60 страниц; одна официальная редакция; без
изменяющих актов). Отклонено 1082 карточки: вне диапазона страниц — 456,
изменяющие акты — 323, нет в официальном банке — 296, больше одной редакции — 7.

Перекосы, которые надо держать в голове:

- **7 из 8 актов короткие, 3–9 страниц.** Только приказ №901 длинный
  (46 страниц), и он почти весь — одна таблица.
- **Оба закона — одного дня (19.02.2018) и одного вида** (упразднение судов).
  По сути это один образец закона в двух экземплярах.
- **Все официальные записи — из IPS**, ни одной из actual.pravo.gov.ru.
- **20 из 120 случайных дней ленты не прошли проверку** коннектора (поля
  `number`/`name` не строки); акты этих дней в отбор не попали.
- **Первая попытка отбора отменена.** В ней (хеш `selection.json`
  `c16712ab187428522fdb2d242d0c8b11ad170ff2b014cccec6dec0ef40eb922c`) фильтр
  изменяющих актов пропустил закон с названием в кавычках, и был выбран
  изменяющий закон №34-ФЗ. Ошибку исправили тестом, отбор повторили с тем же
  seed; итог — 22-ФЗ вместо 34-ФЗ (хеш `e2e6abc5…`). Отменённая попытка
  сохранена в `documents/pool/batch-01/attempt-01-superseded/` и дальше не

## 3. Эталон и его ограничения

- План предполагал автоматический эталон из официального структурного дерева.
  Дерево удалось получить только для **1 акта из 8** (IPS не отдаёт структуру
  четырёх актов; у единственной редакции IPS `rdk = 0`; нет правил идентичности
  для указов и приказов). По решению владельца 21.10.2026 эталон разметил
  **агент (Codex)** по OCR-тексту областей.
- Официальный текст был доступен для 4 актов (pp-1455, pp-884, prikaz-173,
  ukaz-204). По записям разметчика сверка с ним сделана для трёх (pp-1455,
  pp-884, ukaz-204); для prikaz-173 официальный текст не открывался, так как
  номера и границы читались однозначно.
- **Один разметчик**, без второго мнения. Изображения страниц не проверялись:
  разметчик видел только распознанный текст. Ошибки OCR (например, дата
  «18» августа вместо 28 в приказе №901) в эталоне не исправлялись — эталон
  задаёт владельца, а не текст.
- Разметчик не видел выходов проверяемых систем. Эталон и заметки заморожены
  до прогона (`experiments/20261021-batch-01-gold-freeze/freeze.json`).
- **Приказ №901 почти весь — одна большая таблица:** 51 из 73 областей
  принадлежат перечню `S` целиком. Высокий процент на нём мало говорит
  о разборе структуры — достаточно правильно открыть приложение.
- Для необязательного просмотра владельцем отобраны 30 случайных областей
  (seed 20261021): [выборка](M1_04A_POOL_BATCH_1_SAMPLE_2026-10-21.md).

## 6. Что не измерялось

- Точность OCR и текста областей; изображения страниц не сверялись.
- Владельцы сносок и таблиц как отдельная метрика; ячейки таблиц.
- Исключение колонтитулов (верно / ложно) — эталон перечисляет только
  содержательные области.
- Помеченные против молчаливых ошибок считались только по признаку «есть
  владелец / нет владельца», без меток неуверенности.
- Dedoc и LLM-гибрид на этой партии не запускались.
- Кодексы, изменённые законы, изменяющие акты с цитатами поправок, акты
  с разделами и длинные нормативные тексты в партию не входили.
- Повтор прогона на побайтное совпадение не делался (по протоколу —
  один прогон).
