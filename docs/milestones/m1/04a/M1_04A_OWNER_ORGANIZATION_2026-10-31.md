## Сохранение заморозки кода

First-pass runner раньше учитывал только Python-файлы непосредственно в `corpus/`.
После появления вложенного пакета поиск заменён на рекурсивный. Синтетическая
проверка сначала обнаружила отсутствие hash вложенного файла; после изменения она
подтвердила его включение и отказ запуска при изменении до создания результатов.
Старые заморозки сохранены.

`prototype_sha256` в отчёте development runner теперь обозначает только файл входа.
Для фиксации всего алгоритма нужны также файлы `_ocr_owner/*.py`. Их SHA-256 вместе
с hash публичного файла записаны в локальном `final-verification.json`.
Полная first-pass заморозка учитывает их рекурсивно. Исторический
`validate_official_structure_integration.py` относится к прежней проверке native
official-структуры; его состав доказательств не пересматривался.
