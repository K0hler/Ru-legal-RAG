# М1-04А: доработка по полной проверке исходных сканов

Работа продолжает [независимую проверку всех 103 страниц](M1_04A_BASELINE_STRUCTURE_AUDIT_2026-11-01.md).
Полный эталон, исходные сканы и неудачные результаты остаются неизменными.
Это доработка текущих рабочих правил; резервные сканы Task 3 не используются.

## Номера приложений

Адаптер `ocr-owner-ast/2` теперь переносит напечатанный номер из распознанной шапки приложения
в `number_canonical`, `number_display`, `number_components`, `marker_label` и `number_is_explicit`.
Раньше он заполнял эти поля только по маркерам пунктов и других нумерованных единиц,
а у приложения оставлял пустыми. Путь вида `S/AN4` сам по себе не используется как доказательство
напечатанного номера: значение читается из исходного текста шапки с уже существующей грамматикой.
Ненумерованное приложение сохраняет пустые поля; цифры из ссылки на другой документ его номером не становятся.

Сравнение с тем же полным независимым эталоном подтвердило исправление **всех девяти приложений**
исходного СанПиН. Число непрошедших единиц снизилось с 20 до 11: остались только единицы двух
документов, для которых действующая проверка реквизитов не допускает построение дерева.
Владельцы областей и четыре пропущенных продолжения на этом этапе не менялись.
Две полные сборки совпали побайтно; повтор вернул `unchanged`, весь исходный текст и таблицы сохранены.

Артефакты этапа: `data/m1/m1-04a/experiments/20261101-baseline-fixes-01/annex/`
и скрипт `evaluate_annex.py`. Исходный эталон повторно не размечался.
Проверка этапа: 1052 теста прошли, Ruff и М0 78/78 без ошибок; отдельное ревью
не выявило существенных замечаний.

## Продолжения абзацев

Все четыре пропуска на исходных 103 страницах устранены на том же закреплённом эталоне.
Заглавное слово или число теперь может продолжить незаконченный абзац на соседней странице,
если закрывается исходная скобка/цитата либо число следует после сравнительного выражения
вроде «не реже». Для обычных кавычек оставлен консервативный случай одной кавычки в каждом
фрагменте; сложные вложенные кавычки не служат самостоятельным доказательством склейки.
Цитата должна продолжать явно отмеченный пункт; сноски остаются отдельным текстовым потоком.
Новая склейка не проходит через таблицу, новый маркер, заголовок приложения или отдельную страницу без соседства.

Дополнительная проверка обнаружила ошибочные склейки соседних получателей в списках награждённых.
Они воспроизведены отрицательными тестами и устранены до принятия доработки. Сырые тексты,
фрагменты и координаты не меняются; меняется только группировка доказанного продолжения.
Артефакты окончательного этапа: `continuations-accepted/`, `continuation-regression-accepted/`
и `continuation-join-changes-accepted.json` в той же папке эксперимента.
Предыдущие попытки сохранены; для актуальных результатов использовать окончания `accepted`.

Проверка старых сканов отдельно сравнивает владельцев и признаки продолжения. Исторические
метки продолжений не переписываются. Просмотр сканов ФЗ №385 и приказа ФАС №690 подтвердил
буквальные переносы «Российской / Федерации» внутри того же предложения; наличие старой
метки без `+` не используется для изменения исходного эталона. Неоднозначные случаи с несколькими
обычными кавычками остаются несклеенными.
Окончательно изменились 13 признаков продолжения на 237 старых сканах: 11 совпали со старыми
метками, один не входил в старую выборку и подтверждён полным новым эталоном; у приказа
ФАС №690 осталась одна историческая метка без `+`, хотя скан явно показывает продолжение.
Владельцы и все прежние списки ошибок владельцев на 237 документах совпали без изменений.
Полная проверка этапа: 1072 теста прошли, Ruff и М0 78/78 без ошибок. Итоговое ревью — без существенных замечаний.
