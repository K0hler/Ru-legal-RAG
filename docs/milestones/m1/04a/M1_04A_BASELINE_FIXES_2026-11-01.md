# М1-04А: доработка по полной проверке исходных сканов

Работа продолжает [независимую проверку всех 103 страниц](M1_04A_BASELINE_STRUCTURE_AUDIT_2026-11-01.md).
Полный эталон, исходные сканы и неудачные результаты остаются неизменными.
Это доработка текущих рабочих правил; резервные сканы Task 3 не используются.

## Номера приложений

Адаптер `ocr-owner-ast/2` теперь переносит напечатанный номер из распознанной шапки приложения
в `number_canonical`, `number_display`, `number_components`, `marker_label` и `number_is_explicit`.
Раньше он заполнял эти поля только по маркерам пунктов и других нумерованных единиц,
а у приложения оставлял пустыми. Путь вида `S/AN4` сам по себе не используется как доказательство
напечатанного номера: значение читается из исходного текста шапки с уже существующей грамматикой.
Ненумерованное приложение сохраняет пустые поля; цифры из ссылки на другой документ его номером не становятся.

Сравнение с тем же полным независимым эталоном подтвердило исправление **всех девяти приложений**
исходного СанПиН. Число непрошедших единиц снизилось с 20 до 11: остались только единицы двух
документов, для которых действующая проверка реквизитов не допускает построение дерева.
Владельцы областей и четыре пропущенных продолжения на этом этапе не менялись.
Две полные сборки совпали побайтно; повтор вернул `unchanged`, весь исходный текст и таблицы сохранены.

Артефакты этапа: `data/m1/m1-04a/experiments/20261101-baseline-fixes-01/annex/`
и скрипт `evaluate_annex.py`. Исходный эталон повторно не размечался.
Проверка этапа: 1052 теста прошли, Ruff и М0 78/78 без ошибок; отдельное ревью
не выявило существенных замечаний.

## Оставшиеся доработки

- Четыре продолжения абзаца через страницу: заглавное слово или число в начале строки
  сейчас мешает склейке. Сноски и номера страниц не должны разрывать основной текст.
- Семь областей самостоятельных таблиц в приложении без разделов: требуется применение
  правила владельца к ближайшей объемлющей единице с сохранением таблиц, введённых двоеточием, в пункте.
- Отказы по реквизитам №2 и №16 остаются отдельно; проверка реквизитов и загрузчик не изменялись.
