## Попытки

- `…-cycle11-b1` — пустой прогон: правка не применилась (код = v9); итог Б1 — `…-b1-r2`.
- `…-cycle11-b2` — абзацы незакрытой цитаты перестали открывать блок реквизитов даже чертой «____»; 4 акта корпуса
  потеряли по 1–2 области. Итог `…-b2-r2`: исключение только для открытия блока по положению.
- `…-cycle11-b3` — корпус v2 pp-602033590 упал 34 → 13: первая цитата этого акта не распознавалась ещё у v9
  (открывающая строка заканчивается процитированным названием), а снятый маркер процитированного «4.» перестроил
  настоящие пункты. Итог `…-b3-r2`: уточнено правило самозакрытия для прямых кавычек — акт стал безошибочным.
