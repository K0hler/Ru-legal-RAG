# Нормализация официального JSON: повтор и проверка переноса

**Исторический отчёт отключённого адаптера.** После этого результата владелец
принял перенос исходного дерева без реконструкции. Текущее решение и явно
изменённые критерии: [закрытие М1-03А](M1_03A_CLOSURE_2026-10-16.md).
Ниже сохранён результат прежней версии; он не переименован в успешный.

Дата: 16 октября 2026 года. Профиль `official-structure/5`, аудит
`html-structure-audit/3`. Прежняя шестёрка полностью прошла диагностические
проверки: **6/6**, включая **43/43** негативные мутации.
Новый замороженный набор: **2/6 по полным контролям**, технически построены
три документа. **G13 для этого маршрута остаётся fail.**

## Что изменено

- Именованные части кодексов сохраняются с названием, без выдуманного номера.
  Словесные номера частей сопоставляются с напечатанным HTML.
- Неизвестный заголовок утверждённого документа распознаётся по отметке об
  утверждении и совпадающему заголовку. Список названий конкретных актов не нужен.
- Учитываются буквенные пункты, надстрочные индексы и примечания, в том числе
  заголовок примечаний с первым пунктом в одном абзаце.
- 1 663 ненумерованные части ТК сохраняют порядковые номера официального JSON.
  Это явно отмеченные номера источника, а не напечатанные в HTML номера:
  `number_origin=official_sidecar_ordinal`, `number_is_explicit=false`.
  Проверяется непрерывная последовательность частей внутри каждой статьи.
- Один избыточный конец раздела №306 согласован с концом родительского
  приложения и следующим подтверждённым приложением. Семь отсутствующих
  конечных ссылок ТК восстановлены по следующей подтверждённой границе.
  Исходные диапазоны либо имена отсутствующих ссылок сохранены с основанием
  нормализации. Начало и источник родителя не переписываются.
- Шесть пропущенных оглавлением буквенных пунктов УК восстановлены по
  непрерывному списку после двоеточия. Продолжения и формулы следуют полному
  диапазону пункта; напечатанное завершение списка возвращает контекст родителя.
- Ячейки сохраняют положение в таблице и отдельную связь с пунктом закона.
  Аудит проверяет принадлежность текста и отличает ссылку «Часть 1 настоящей
  статьи…» от заголовка верхней части.

Правила общие: номер, дата, название, имя файла и хеш акта не выбирают
производственную ветвь. Неоднозначные границы, неизвестные начала, пересечение
листовых узлов и содержательные промежутки остаются ошибками. Проверка пустоты
промежутка учитывает изображения и таблицы, включая не содержащие текста.

Контроли имеют два разных уровня: независимое чтение напечатанных заголовков,
текста и media из HTML; отдельное воспроизведение заявленных JSON связей через
DOM-позиции. Второй уровень проверяет выполнение контракта источника, включая
ненапечатанные номера частей. Он не является независимой юридической экспертизой
правильности официального оглавления. Контроли нового набора готовятся до его AST.

Негативные проверки меняют родителя, номер, исходный и нормализованный текст,
принадлежность абзаца/ячейки/изображения/таблицы, HTML media и координаты источника.
Дополнительные синтетические проверки смещают координаты вместе с байтовой
ссылкой, чтобы обнаружение не зависело только от их внутреннего несоответствия.

Причины первого отказа каждого неподдержанного документа:

1. **181-ФЗ:** появился `unit=абзац`, подпись `*абзац 1`. Такой тип и его
   ненапечатанная нумерация ещё не поддерживаются. Сервисный JSON не признан
   ошибочным только из-за неподдержанного типа.
2. **БК:** заголовок `ЧАСТЬ ПЕРВАЯ. ОБЩИЕ ПОЛОЖЕНИЯ` содержит название после
   словесного номера. Текущая нормализация принимает самостоятельный заголовок
   `ЧАСТЬ ПЕРВАЯ`, но пока блокирует этот более полный вариант.
3. **ГПК:** `unit=подраздел`, `ПОДРАЗДЕЛ I. ПРИКАЗНОЕ ПРОИЗВОДСТВО` — отдельный
   тип структурного деления, которого нет в текущем адаптере. Он не заменяется
   молча главой или обычным абзацем.
4. **384-ФЗ:** компилятор выполнил две одинаковые полные сборки и неизменный
   повтор; исходные ID, текст, media и аудит проходят. Два замечания принадлежат
   контрольному читателю: он сравнил ближайшую **цитируемую статью 5.1** с
   ожидаемой основной статьёй 43. Проверка цепочки подтверждает наличие обоих
   предков в правильном порядке. Это выявленное ограничение читателя, а не
   подтверждённая ошибка дерева. Замороженное решение остаётся fail; задним
   числом читатель и итог этой выборки не изменялись.

Матрица: федеральные законы **0/2**, кодексы **0/2**, постановления **2/2**.
Все 14 доступных негативных мутаций для двух полностью прошедших документов
обнаружены. Для провалившегося базового контроля мутации не засчитываются как
доказательство качества проверяющего. Техническое сохранение — **3/6**,
полная квалификация — **2/6**. Ни один провалившийся документ не заменён.
