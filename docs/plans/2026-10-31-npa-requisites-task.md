## Обязательно исправить загрузчик

- [x] Обрабатывать пустое название, включая пустую строку и отсутствие значения, когда карточка
  существует и содержит остальные необходимые сведения.
- [x] Не путать такую карточку с отсутствующей записью или недоступностью сайта.
- [x] Сохранять исходный ответ сайта и его хеш; не менять прежние архивы и замороженные результаты.
- [x] Проверить реальные примеры, повторную загрузку и отказы при неверной привязке источника/файла.

Подтверждённый пример: публикация `0001202505100031`, распоряжение №1165-р от 08.05.2025.
У карточки пустое название, но есть дата, номер, вид и издатель; нынешний загрузчик такой вариант
отбрасывал. Исправлено 03.11.2026 в opt-in адаптере; замороженный контракт М0 сохранён.

## Реквизиты из официальной карточки

- [x] Для используемого PDF-маршрута определить достаточные сведения: дата акта, полный номер,
  вид и именованный издатель. Название необязательно. Наличие сведений в карточке не зависит от вида OCR.
- [x] Разделить недоступность исходных сведений, пустые обязательные поля и диагностику OCR.
  Отсутствие локально привязанной карточки не называть отсутствием записи на сайте.
- [x] Измерить на известных документах число нерешённых случаев и их причины. Наличие карточки само
  по себе не показывает, сколько документов потребует внимания.
- [x] Показывать «Из официальной карточки» либо «Недостаточно сведений официальной карточки».
  Нераспознанные OCR-реквизиты не блокируют структуру и не создают ручное задание при полной карточке.

Численный порог нагрузки не устанавливался. Внимания требуют отсутствующие необходимые сведения
источника или обнаруженные противоречия, а не само отсутствие совпадения с OCR.
