> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** подготовить стенды разработки после меры партии 8 и holdout корпуса, закрыть четыре крупнейших известных
класса ошибок v7, заморозить v8 и измерить её на новых данных.

по одному классу за задачу, сверху вниз по числу ошибок, каждое правило с регрессией на обоих стендах. Этап В —
заморозка v8 и мера на свежей партии пула 9; новый корпус JSON — отдельное решение владельца.

**Tech Stack:** Python 3 (`PYTHONPATH=src`), pytest, скрипты `docs/assets/`, OCR-Lab Docker dotsmocr, `codex exec`.

**Spec:** [карта задачи](../milestones/m1/04a/M1_04A_MAP_2026-10-25.md),
[протокол](../milestones/m1/04a/M1_04A_EVALUATION_PROTOCOL_2026-10-20.md) §5–8,
[соглашение v2](../milestones/m1/04a/M1_04A_ANNOTATION_CONVENTION_v2.md) §5, §6, §6.1.

## Global Constraints

- Работа прямо в `main`; каждая задача — свой коммит; ближайший `AGENTS.md` обновляется в той же задаче.
- Правила общие: без условий на номер, дату, название или хеш акта.
- Замороженные эталоны, выходы прогонов и копии прототипов пишутся один раз; неудачные попытки сохраняются рядом
  с суффиксом `attemptN`, не удаляются.
- Регрессия правила принимается, только если **ни один документ** на обоих стендах не стал хуже базы этапа А.
- Каждое новое правило — тест в `tests/legal_rag/corpus/test_ocr_logical_structure.py`, который падает на v7.
- `documents/reserved/` не открывать; фамилии из указов о судьях не попадают в документы; `sample-30` — только локально.
- Отчёты для владельца — по-русски.

## Review Focus

1. Правило шапок «Приложение № N к <Документу>» (Б1) не должно открывать приложение на ссылке в тексте пункта
   («согласно приложению № 2 к Регламенту») — тест на ссылку внутри абзаца.
2. Правило «Примечание.» (Б2) не должно забирать обычный абзац, начинающийся словом «Примечание» в середине пункта
   акта без статей — тест на постановление с пунктами.
3. Ослабление защиты цитат C5 (Б3) не должно вернуть прежний перенос текста пула в цитату (`cross_scope_v2` на пуле
   должен остаться прежним) — регрессия пула обязательна, не только корпус.
4. Стенд «все 100 актов» (А2) не должен молча заменить старые выходы: новый каталог, старые `dev-proj4`
   и `holdout-proj4` не трогаются.
5. Партия 8 в регрессии берёт эталон `gold-forms`, а не `gold`, иначе база приказа ФАС будет занижена на 130 областей.

## Этап Б. Цикл 9: правила по классам, сверху вниз

`docs/assets/ocr_logical_structure.py` → регрессия пула (`--baseline` из А3, exit 0) и корпуса (по документам не хуже

не проходит — попытка сохраняется как `attemptN`, правило переделывается; после трёх неудач класс откладывается
