# М1-04А: партия 3 проверочного пула с кодексами — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** измерить замороженный прототип v1 с первого раза на партии 3. В неё входят кодексы, у которых на портале есть исходная публикация, и разнообразные акты остальных видов, включая распоряжения Правительства. Эталон размечается по соглашению v2.

**Architecture:** перед отбором:
- закрываются мелкие замечания по инструментам отбора, загрузки и вывода эталона v2;
- делается перепись кодексов по метаданным.

Дальше тот же конвейер, что в партиях 1–2: отбор, загрузка через адаптер `publication-pravo-pool/2`, OCR, слепая разметка Codex, заморозка, один прогон, отчёт. Прототип и оценщик не меняются, измеряется v1 (sha256 `a16c1405…`).

**Tech Stack:** Python 3, `docs/assets/*m1_04a*`, `legal_rag.sources.publication_pool`, Docker OCR-Lab dots.mocr, Codex для разметки, pytest, ruff.

**Spec:** [протокол](../milestones/m1/04a/M1_04A_EVALUATION_PROTOCOL_2026-10-20.md), [соглашение v2](../milestones/m1/04a/M1_04A_ANNOTATION_CONVENTION_v2.md), [баг-репорт загрузки](../milestones/m1/04a/M1_04A_BUG_SOURCE_ACQUISITION_2026-10-22.md), решения владельца 22.10.2026:
- приложения Правил — `S/AN<n>`;
- «N.M» вкладывается в «N.»;
- кодексы до 500 страниц.

## Global Constraints

- Отбор только по метаданным; список кодексов и `selection.json` замораживаются до загрузки тел.
- Только существующие эндпоинты, интервал ≥ 1 с; тела актов не читаются до OCR.
- Партии 1–2, резерв и их данные не меняются; новые данные — в `data/m1/m1-04a/`.
- Прототип v1 и оценщик заморожены; правила только общие.
- Разметчик не видит выходов систем, в том числе этапа 2; эталон замораживается до прогона.
- Отчёты на русском, сначала простая таблица; каждый Task — коммит в `main`.

## Review Focus

1. **Кодекс на 480 страниц:**
   - OCR идёт долго — запуск в фоне, повтор из сохранённых ответов;
   - разметку делят несколько заданий Codex по диапазонам страниц, и на стыке нельзя потерять область действия (глава или статья продолжается);
   - каждый следующий разметчик получает «шапку» — текущий раздел, главу и статью на первой странице своего диапазона.
2. **Кодекс с собственными приложениями или ссылками на другие кодексы:** ссылка вида «статья 5 настоящего Кодекса» не открывает статью.
3. **Распоряжение без названия в карточке:** проходит через новую обёртку, предупреждение записано.
4. **В переписи только один кодекс:** квота кодексов равна числу найденных кодексов, это не ошибка.
