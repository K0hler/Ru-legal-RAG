# Независимый контроль юридической структуры

**Goal:** выявлять расхождения HTML и дерева на каждом входе с официальной
разметкой и восстанавливать только однозначные пропущенные положения.
**Architecture:** независимый проход по исходному HTML, сверка с готовым AST,
отчёт с критичностью и исходными координатами; ограниченное восстановление
пропущенного соседнего пункта по явной надстрочной нумерации.
**Tech Stack:** существующий Python/BeautifulSoup, без новых зависимостей.
**Spec:** одобренная пользователем схема из четырёх шагов в текущем чате;
`M1_03A_STRUCTURE_GAP_TRIAGE_2026-10-15.md`.

## Ограничения и решения

- Подтверждение пользователя относится к описанной схеме; выполняем в текущем
  чате на main. Дополнительное подтверждение того же дизайна не требуется.
- Работа ограничена поддерживаемым native HTML + official sidecar маршрутом.
  PDF/OCR, юридический допуск и G13 остаются отдельными задачами.
- Нет правил по номеру акта, дате, заголовку, имени файла или хешу документа.
- Исходные HTML/JSON, M0 freeze, прежние попытки и `corpus-input/1` не меняются.
- Последовательность номеров не доказывает пропуск. Восстановление требует
  существующего HTML-маркера, типографики, установленного родителя и границ.
- Источник JSON и выведенное из HTML исправление различимы: сохраняются
  первоначальный диапазон, причина, координаты и новое адресное положение.
- Неоднозначность даёт критическое замечание, а не выдуманный узел.
- Крупный абзац формы/поправки допустим в правильном родителе без ложного quote.

## Review focus

1. Неизвестная глава/раздел отсутствует в JSON → независимый scanner находит
   именованный маркер, Roman/decimal/superscript проверяются отдельными тестами.
2. Перенос формулы/примечаний к предыдущему пункту → границы восстановленного
   пункта включают всё его содержимое, но не следующую подтверждённую единицу.
3. Вставка в цитате или форме стала нормой акта → контекст запрещает восстановление.
4. Простое отсутствие номера стало «исправлением» → без явного маркера нет узла.
5. Снятый блокер оставил неверную точную границу → fallback хранит цельный
   абзац в исходном положении; неверный дочерний quote не создаётся.
