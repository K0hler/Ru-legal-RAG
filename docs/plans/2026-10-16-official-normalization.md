# Нормализация официальной структуры и повторная проверка

**Goal:** общими правилами устранить подтверждённые ограничения маршрута,
полностью проверить прежние шесть актов и только после 6/6 скачать новый
независимый набор. Пользователь прямо подтвердил эту последовательность.
**Architecture:** существующий `corpus-input/2`, типизация/нумерация из контекста,
доказуемое согласование границ HTML и JSON с сохранением source-declared spans;
независимые HTML controls проверяют узлы, текст и media. Новых зависимостей нет.
**Spec:** предыдущий анализ в чате, `M1_03A_OFFICIAL_JSON_TRANSFER_2026-10-16.md`.

## Ограничения

- Main; исходные архивы, прежние отчёты, M0 freeze и v1 output не менять.
- Никаких правил по номеру/дате/названию акта/файлу/SHA.
- Именованная часть не получает выдуманный порядковый номер. Словесный номер
  нормализуется только когда он явно присутствует и совпадает с HTML.
- Неизвестное вложение признаётся утверждённым текстом по HTML-свидетельству
  утверждения и совпадающему заголовку, а не по новому whitelist названий актов.
- Исправляется только доказуемый конец диапазона. Начало, родитель и исходные
  координаты сохраняются; неоднозначный конфликт остаётся критическим.
- Старые шесть — development/regression, не новая G13-выборка после доработки.
- Новый набор выбирается/получается только после полного 6/6, версии фиксируются
  до чтения новых тел. При отказе нового набора не подменять документы и не
  подгонять замороженный профиль в рамках того же квалификационного прогона.
