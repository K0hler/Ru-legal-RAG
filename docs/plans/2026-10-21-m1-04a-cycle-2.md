# М1-04А, цикл 2: доработка прототипа по классам ошибок и партия 2 — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** закрыть три главных класса ошибок партии 1 общими правилами в прототипе: именованные единицы закона, подписи и реквизиты после последней нормы, нераспознанные подписи приложенных документов. Затем измерить новую версию с первого раза на партии 2 — более длинных и разнообразных актах, включая изменённые законы и кодексы.

**Architecture:** трек A меняет только прототип `docs/assets/ocr_logical_structure.py` и измеряется на 16 документах разработки: 8 прежних и 8 из партии 1, правило оценки v1. Трек B готовит партию 2 по протоколу:
- отбор только по метаданным, без условия «одна редакция» (эталон теперь размечается по OCR, официальная редакция не нужна);
- загрузка PDF;
- OCR;
- слепая разметка Codex по соглашению v1 и заморозка;
- один прогон замороженной версии из трека A.

Партия 2 отбирается и размечается после заморозки трека A, а разработчики трека A документы партии 2 не открывают.

**Tech Stack:** Python 3 стандартной библиотеки, существующие скрипты `docs/assets/*m1_04a*`, Docker OCR-Lab dots.mocr, Codex для разметки, pytest 8.4, ruff 0.14.

**Spec:** [протокол оценки](../milestones/m1/04a/M1_04A_EVALUATION_PROTOCOL_2026-10-20.md) (разделы 2–9), [соглашение о разметке v1](../milestones/m1/04a/M1_04A_ANNOTATION_CONVENTION_v1.md), [отчёт партии 1](../milestones/m1/04a/M1_04A_POOL_BATCH_1_2026-10-21.md).

## Global Constraints

- Правила только общие: никаких условий под номер, дату, название, имя файла или хеш конкретного акта.
- Трек A работает только на документах разработки: 8 из `data/m1/experiments/m1-04a-20261017-logical-v1/inputs` и 8 из `data/m1/m1-04a/documents/pool/batch-01`. Партия 2 и резерв не открываются.
- Регрессия запрещена: на прежних 8 документах прототип сохраняет 849/849 без разделов. Любое снижение на документе партии 1 объясняется в отчёте — улучшение в среднем его не оправдывает.
- Каждая версия прототипа получает новый `VERSION` и снимок с хешем. Старая версия `code-final` (a7b81b59…) остаётся доступной для сравнения.
- Оценка — по правилу v1 (Picture и колонтитулы не оцениваются), режим «без разделов» — главный.
- Данные для разметчика не содержат выходов этапов 2 и 3 (без `join`/`P`); эталон замораживается до прогона.
- Новые данные — только в `data/m1/m1-04a/` по схеме `data/AGENTS.md`; выходы неизменяемы.
- Отчёты на русском, сначала простая таблица для владельца. Каждый Task заканчивается коммитом в `main`.
- Команды — PowerShell из корня: `$env:PYTHONPATH = "src"; .venv\Scripts\python.exe …`.
