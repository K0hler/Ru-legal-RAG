# Проверка переноса официального HTML + JSON

**Goal:** выполнить утверждённый G13-протокол для `official-structure/4` на
шести независимых актах, не меняя производственные правила.
**Architecture:** отдельный диагностический запуск существующего транспорта М0,
валидаторов карточек/редакций, `StructureConnector`, immutable acquisition и
`corpus-input/2`; независимые исходные controls до AST, полный compiler replay.
**Tech Stack:** существующий Python/BS4 runtime, без новых зависимостей.
**Spec:** `M1_IMPLEMENTATION_PLAN.md`, Shared Legal Structure And Transfer Checks;
пользователь подтвердил получение документов и прогон новым маршрутом.

## Один приёмочный пункт

- [x] Зафиксировать выбор до чтения тел: 218-ФЗ от 13.07.2015, 229-ФЗ от
  02.10.2007; УК РФ 63-ФЗ от 13.06.1996, ТК РФ 197-ФЗ от 30.12.2001;
  ПП РФ №306 от 23.05.2006 и №290 от 03.04.2013. Это разные непилотные акты,
  отсутствующие в прежних development/transfer cohorts. Никаких подстановок
  после неудачного разбора. Производственные версии/SHA зафиксировать до тел.
- [x] Получить поиск, карточку, редакции, текст и официальный JSON с одной
  редакцией. Для новых актов использовать отдельную диагностическую обвязку
  замороженных транспорта/валидаторов, не расширять production pilot allowlists.
  Сохранить per-capture transport и точные разрешения на оба raw SHA.
- [x] Подготовить независимые DOM controls до запуска AST. Проверить полный текст,
  идентичность, явные номера и родителей, таблицы/изображения/приложения/исключения.
- [x] Запустить каждый полученный вход. Для успешных выполнить две полные сборки

  сохранить исходную ошибку и два одинаковых повторных отказа с диагностикой.
  Изменение правил потребовало бы отдельного запуска и других отложенных актов.
- [x] Независимая финальная проверка протокола и существенных результатов,
  M0 gate, соответствующие regressions, русский отчёт/README/AGENTS и commit main.
  Только полная матрица 2/2 на каждое семейство/формат позволяет принять этот
  маршрут. Юридический допуск, OCR и весь М1 этим не закрываются.

## Review focus

- Историческая редакция/другой текст не должны связываться с JSON выбранной редакции.
- Повторение sidecar не является независимой проверкой родителей по HTML.
- Потерянный текст или сохранённый текст под неверным родителем блокирует приёмку.
- Неудачный контрольный reader не превращается в pass и не заменяет документ.
- Записанный текущий снимок не объявляется применимой на дату редакцией.
