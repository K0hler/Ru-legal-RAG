# Интеграция официальной структуры М0 → М1

**Goal:** сохранять исходный HTML и JSON-структуру одной редакции, строить
диагностическое дерево и явно доразбирать отсутствующие в JSON конструкции.
**Architecture:** совместимое дополнение М0 поверх существующего acquisition;
новый вход `corpus-input/2`; отдельный source-format adapter в М1.
**Tech Stack:** Python, существующий HTML lexer, BeautifulSoup, pytest.
**Spec:** подтверждённое владельцем предложение и
`M1_03A_OFFICIAL_STRUCTURE_EXPERIMENT_2026-10-15.md`.

## Ограничения

- Работа на main; исходные архивы, эксперименты и замороженный М0 неизменны.
- Старый `corpus-input/1` и `edition-candidate/1` воспроизводятся прежним путём.
- Новый JSON нельзя незаметно проигнорировать при ошибке. Разные редакции,
  неверные номера, пересечения диапазонов и повреждения блокируют обработку.
- Разрешение охватывает все текстовые активы нового входа. Юридический допуск,
  применимость на дату и G13 не следуют из успешного построения дерева.
- Неизвестные конструкции сохраняются с причиной; нет подбора правил по акту.
- Область редакторского примечания не выводится из соседства абзацев.

## Review focus

1. Редакции перепутаны → отрицательные тесты селекторов и хешей связки.
2. Потеря/дублирование текста → ровно однократный учёт токенов и регионов.
3. Цитата стала статьёй исходного закона → отдельный quote под исходным пунктом.
4. Нумерация формы стала правовой нормой → list_item с контекстом формы.
5. Совместимость только заявлена → старый replay, M0 gate, полный прогон семи актов.
